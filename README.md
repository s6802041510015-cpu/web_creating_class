# WebHTML Class

เว็บเรียนรู้รายวิชา **การสร้างเว็บไซต์ (Website Creating)** สำหรับนักเรียน ปวช. 1 พัฒนาด้วย React, TypeScript, Vite, Tailwind CSS และ React Router

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงในเทอร์มินัล

## ตรวจสอบ

```bash
npm run typecheck
npm run build
```

## เนื้อหาที่มีแล้ว

- บท 00–05 พร้อมวัตถุประสงค์ กิจกรรมสำรวจ ตัวอย่าง และ Quick Check ตามแผนการสอน
- Tag Explorer และ HTML Structure Explorer
- Code Lab สำหรับเขียน HTML และดูผลใน sandboxed iframe ที่ไม่อนุญาตให้รัน JavaScript
- Workshop 3 หน้า พร้อมตัวแก้ไข Preview ขั้นตอนงาน และ Checklist สำหรับตรวจด้วยตนเอง
- แบบทดสอบก่อนเรียนและหลังเรียน ชุดละ 12 ข้อ พร้อมผลคะแนนตามวัตถุประสงค์
- บท 00 และ 01 เข้าได้ตั้งแต่เริ่มต้น ส่วนบท 02–05 ปลดล็อกทีละบทเมื่อเรียนบทก่อนหน้าจบ โดยบันทึกความคืบหน้าในเบราว์เซอร์และซิงก์ตามบัญชี LINE เมื่อตั้งค่าระบบแล้ว

## ข้อมูลและขอบเขต

ข้อมูลบทเรียนอยู่ใน `src/data/lessons.ts` ข้อสอบอยู่ใน `src/data/preTest.ts` และ `src/data/postTest.ts` รายละเอียดงานอยู่ใน `src/data/finalProject.ts`

เว็บนักเรียนเข้าสู่ระบบผ่าน LINE LIFF ครั้งแรกต้องลงทะเบียนรหัสนักเรียน ชื่อ-นามสกุล เลขที่ และชั้น/ห้อง ข้อมูลนี้บันทึกใน Google Sheet แล้วจึงเลือกซิงก์บทเรียน คะแนน และสถานะกิจกรรมผ่าน Vercel API โค้ดร่างของ Code Lab และ Workshop เก็บเฉพาะในอุปกรณ์

AI ผู้ช่วยใช้ Gemini โดยเก็บคีย์บน Vercel และยืนยันบัญชี LINE ก่อนเรียกใช้ แชทซ่อนบนแบบทดสอบ ส่วนเว็บครูอยู่ที่ `/teacher` ใช้ชื่อผู้ใช้และรหัสผ่านของครูเพื่อดูความก้าวหน้าและจัดห้องเรียน ขั้นตอนตั้งค่าบัญชีครูและ Google Sheets อยู่ใน [vercel-api/README.md](vercel-api/README.md)
