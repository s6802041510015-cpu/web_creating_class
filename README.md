# WebQuest Studio

เว็บเรียนรู้รายวิชา **การสร้างเว็บไซต์ (Website Creating)** สำหรับนักเรียน ปวช. 1 พัฒนาด้วย React, TypeScript, Vite, Tailwind CSS และ React Router

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงในเทอร์มินัล

## ตรวจสอบ

```bash
npm run typecheck
npm run build
```

## เนื้อหาที่มีแล้ว

- บท 00–05 พร้อมวัตถุประสงค์ กิจกรรมสำรวจ ตัวอย่าง และ Quick Check ตามแผนการสอน
- Tag Explorer และ HTML Structure Explorer
- Code Lab สำหรับเขียน HTML และดูผลใน sandboxed iframe ที่ไม่อนุญาตให้รัน JavaScript
- Workshop 3 หน้า พร้อมตัวแก้ไข Preview ขั้นตอนงาน และ Checklist สำหรับตรวจด้วยตนเอง
- แบบทดสอบก่อนเรียนและหลังเรียน ชุดละ 12 ข้อ พร้อมผลคะแนนตามวัตถุประสงค์
- บท 00 และ 01 เข้าได้ตั้งแต่เริ่มต้น ส่วนบท 02–05 ปลดล็อกทีละบทเมื่อเรียนบทก่อนหน้าจบ โดยบันทึกความคืบหน้าในเบราว์เซอร์

## ข้อมูลและขอบเขต

ข้อมูลบทเรียนอยู่ใน `src/data/lessons.ts` ข้อสอบอยู่ใน `src/data/preTest.ts` และ `src/data/postTest.ts` รายละเอียดงานอยู่ใน `src/data/finalProject.ts`

โค้ด Workshop และผลแบบทดสอบอยู่ในหน่วยความจำของเบราว์เซอร์ระหว่างใช้งานหน้าเว็บเท่านั้น เมื่อรีโหลดข้อมูลจะเริ่มใหม่ ส่วนความคืบหน้าบทเรียนบันทึกใน `localStorage` ของเบราว์เซอร์ ยังไม่มีฐานข้อมูล การเข้าสู่ระบบ หรือ AI
