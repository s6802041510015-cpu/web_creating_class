## เริ่มจากลิงก์ไหน

- **เว็บเรียน:** [เปิด WebHTML Class](https://s6802041510015-cpu.github.io/web_creating_class/) หรือกดปุ่มเรียนใน LINE OA
- **เว็บครู:** [เปิดหน้าความก้าวหน้านักเรียน](https://s6802041510015-cpu.github.io/web_creating_class/teacher)
- **เว็บลาเรียน:** [เปิด WebHTML Leave](https://webhtml-leave.vercel.app/) หรือกดปุ่มลาเรียนใน LINE OA โดยตรง

เว็บเรียนและเว็บลาเรียนใช้บัญชี LINE ของนักเรียน ส่วนเว็บครูใช้ชื่อผู้ใช้และรหัสผ่านที่ผู้ดูแลมอบให้

## 1. นักเรียน: เริ่มใช้งานเว็บเรียน

### 1.1 เข้าสู่ระบบและลงทะเบียนครั้งแรก

1. เปิดเว็บเรียนจากเมนูของ LINE OA หรือ [ลิงก์ LIFF เว็บเรียน](https://liff.line.me/2012268768-BPIlGmOb) หากเปิดในเบราว์เซอร์ทั่วไป ให้กด **เข้าสู่ระบบด้วย LINE**
2. เมื่อเข้าสู่ระบบครั้งแรก หน้า **ระบุข้อมูลนักเรียน** จะให้กรอก **รหัสนักเรียน ชื่อ-นามสกุล เลขที่ และชั้น/ห้อง** ใช้ข้อมูลตามทะเบียนเรียน แล้วกด **บันทึกและเริ่มเรียน**
3. ตรวจข้อมูลก่อนบันทึก เพราะนักเรียนแก้ข้อมูลลงทะเบียนเองไม่ได้ หากกรอกผิดให้แจ้งครู ชื่อที่ลงทะเบียนจะใช้ระบุตัวตนแทนชื่อโปรไฟล์ LINE ที่อาจไม่ใช่ชื่อจริง
4. หากระบบถามเรื่องการบันทึกการเรียนกับบัญชี LINE ให้เลือก **ยอมรับและเริ่มใหม่** หรือ **ยอมรับและนำข้อมูลเดิมในเครื่องนี้เข้า** ตามกรณี เพื่อซิงก์ความก้าวหน้าข้ามอุปกรณ์

### 1.2 ลำดับการเรียน

1. เริ่มจาก **แบบทดสอบก่อนเรียน** เพื่อบันทึกคะแนนก่อนเรียน
2. เปิดเมนู **บทเรียน** บท **00 เตรียมความพร้อม** และ **01 ความหมายของภาษา HTML** เปิดให้เข้าได้ตั้งแต่แรก ส่วนบท 02-05 จะปลดล็อกทีละบทเมื่อเรียนบทก่อนหน้าเสร็จ
3. ในแต่ละบท ใช้แถบขั้นตอนเพื่ออ่านเนื้อหา ดูตัวอย่าง ลองกิจกรรมและโมเดล 3D ที่หมุนมุมมองได้ แล้วกดปุ่มจบบทเรียนเมื่อทำครบ จึงใช้ปุ่ม **บทเรียนถัดไป** ได้
4. เมื่อทำแบบทดสอบก่อนเรียนและเรียนครบ **6 บท** แล้ว **แบบทดสอบหลังเรียน** จึงเปิดให้ทำ
5. เปิด **ความก้าวหน้าของฉัน** เพื่อดูบทเรียนที่จบ คะแนน และสถานะกิจกรรม

> การตรวจความก้าวหน้าในเว็บอาศัยการกดจบบทเรียนและผลกิจกรรมของผู้เรียน ครูควรใช้ข้อมูลนี้ประกอบการติดตาม ไม่ใช่หลักฐานว่าผู้เรียนเข้าใจเนื้อหาทั้งหมดแล้ว

### 1.3 ใช้ Code Lab

1. กดเมนู **Code Lab** แล้วเลือกหัวข้อฝึกจากแถบ Practice
2. อ่านโจทย์และเกณฑ์ตรวจ เขียน HTML ในช่องโค้ด แล้วกด **Run** เพื่อดูผลที่ Preview
3. กด **ตรวจคำตอบ** ระบบจะแสดงข้อที่ผ่านและคำแนะนำของข้อที่ยังไม่ผ่าน แก้โค้ดแล้วตรวจซ้ำได้
4. ใช้ปุ่ม Hint เมื่ออยากได้แนวทาง และใช้ **ถามผู้ช่วย AI** หากยังติดขัด

สถานะหัวข้อที่ตรวจผ่านซิงก์กับบัญชี LINE เมื่อเปิดใช้การซิงก์แล้ว แต่ **โค้ดร่างเก็บเฉพาะเบราว์เซอร์ของอุปกรณ์ที่เขียน**

### 1.4 ใช้ Workshop

1. กดเมนู **Workshop** และอ่านขั้นตอนกับข้อกำหนดของแต่ละหน้า
2. สลับแท็บเว็บไซต์ **3 หน้า** เพื่อเขียน HTML และกด Run ดู Preview ลิงก์ระหว่างหน้าสามารถใช้ `page1.html`, `page2.html` และ `page3.html`
3. กด **ดาวน์โหลดหน้านี้** เพื่อเก็บไฟล์ HTML ของหน้าที่กำลังเปิด
4. ติ๊ก **ตรวจผลงานของคุณ** เมื่อได้ตรวจแต่ละหัวข้อด้วยตนเอง Checklist นี้ยังไม่ใช่คะแนนจากครูหรือการตรวจอัตโนมัติ

ระบบซิงก์สถานะ Checklist ได้ แต่โค้ดร่าง Workshop อยู่เฉพาะอุปกรณ์ ควรดาวน์โหลดไฟล์ก่อนเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์

### 1.5 ถามผู้ช่วย AI

- กด **ถามผู้ช่วย AI** ที่มุมหน้าเว็บ พิมพ์สิ่งที่สงสัย เช่น “แท็ก `img` ต้องใส่อะไรบ้าง” หรือ “โค้ดส่วนนี้ผิดตรงไหน”
- ผู้ช่วยรับบริบทของหน้าที่กำลังเรียน และตั้งค่าให้ช่วยคิดทีละขั้น ใน Code Lab และ Workshop ผู้เรียนเลือก **แนบโค้ดปัจจุบันเพื่อขอคำแนะนำ** ได้เอง
- หน้าแบบทดสอบก่อนเรียนและหลังเรียนไม่มีปุ่มแชท ผู้ช่วยอาจตอบคลาดเคลื่อน จึงควรตรวจคำแนะนำกับบทเรียนหรือถามครูเมื่อไม่แน่ใจ

## 2. นักเรียน: แจ้งลาเรียน

1. กด **ลาเรียน** ใน LINE OA เพื่อเข้าเว็บลาเรียนโดยตรง หรือเปิด [เว็บลาเรียน](https://webhtml-leave.vercel.app/) แล้วเข้าสู่ระบบด้วย LINE
2. กด **เริ่มแจ้งลา** หรือ **แจ้งลาเรียน** หากเคยลงทะเบียนในเว็บเรียน ข้อมูลนักเรียนจะถูกนำมาเติมให้ หากยังไม่เคยลงทะเบียน ให้กรอกรหัสนักเรียน ชื่อ-นามสกุล เลขที่ และชั้น/ห้องในเว็บลาครั้งแรก
3. เลือกประเภท **ลาป่วย ลากิจ หรืออื่น ๆ** ระบุวันที่เริ่มและสิ้นสุด เลือกช่วงเวลา **เต็มวัน ช่วงเช้า ช่วงบ่าย หรือระบุเวลาเอง** และเขียนเหตุผลอย่างน้อย 5 ตัวอักษร
4. หากเลือก **ระบุเวลาเอง** ให้กรอกเวลาเริ่มและเวลาสิ้นสุด โดยเวลาสิ้นสุดต้องหลังเวลาเริ่ม ตัวเลือกนี้ใช้ได้กับการลา **วันเดียว**
5. กด **ตรวจสอบข้อมูล** อ่านรายละเอียดอีกครั้ง แล้วกด **ยืนยันส่งคำขอ**
6. ดูสถานะ **รอพิจารณา / อนุมัติ / ไม่อนุมัติ** และเหตุผลจากครูได้ใน **ประวัติการลา** ระบบจะพยายามส่งข้อความรับเรื่องและผลการพิจารณาเข้า LINE OA ด้วย

เมื่อส่งแล้วควรดูรายการในประวัติการลาเพื่อยืนยันว่าระบบบันทึกสำเร็จ หากข้อความ LINE ไม่มาถึง ยังตรวจผลในเว็บลาเรียนได้

## 3. ครู: ดูการเรียนและจัดห้อง

1. เปิด [เว็บครู](https://s6802041510015-cpu.github.io/web_creating_class/teacher) กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ที่ได้รับ แล้วกด **เข้าสู่ระบบ** ครูทุกบัญชีที่ตั้งไว้เห็นข้อมูลชุดเดียวกัน
2. หน้า **ความก้าวหน้านักเรียน** แสดงจำนวนนักเรียน ผู้ที่ทำแบบทดสอบก่อนเรียน ผู้ที่เรียนครบ และผู้ที่ทำแบบทดสอบหลังเรียน ตารางรายชื่อแสดงบทเรียน คะแนน Code Lab Workshop และวันอัปเดต
3. ใช้ช่องค้นหาหรือเมนูกรองห้องเพื่อดูนักเรียนเฉพาะกลุ่ม หากต้องแก้ห้อง ให้พิมพ์ชื่อห้องในแถวของนักเรียนแล้วกด **บันทึก**
4. หากต้องการแท็บ Google Sheet ของห้อง ให้เลือกห้องจากตัวกรองแล้วกด **สร้างแท็บห้องนี้** หลังสร้างจะมีปุ่ม **เปิดแท็บห้องนี้** การกดซ้ำใช้แท็บเดิม แท็บห้องเป็นมุมมองที่ดึงข้อมูลจาก `Students`; ควรแก้ข้อมูลผ่านเว็บครูหรือแท็บ `Students`
5. กด **เปิด Google Sheet** เพื่อดูข้อมูลต้นทาง บัญชี Google ของครูต้องได้รับสิทธิ์เข้าถึง Sheet แยกต่างหาก แม้จะล็อกอินเว็บครูได้แล้ว

## 4. ครู: พิจารณาคำขอลา

1. หลังเข้าสู่ระบบเว็บครู กดเมนู **คำขอลาเรียน** หรือเปิด [หน้าคำขอลา](https://s6802041510015-cpu.github.io/web_creating_class/teacher/leaves)
2. ดูจำนวนรายการรอพิจารณา อนุมัติ และไม่อนุมัติ ใช้ช่องค้นหา ตัวกรองห้อง และตัวกรองสถานะเพื่อหารายการ
3. อ่านชื่อ วัน ช่วงเวลา และเหตุผล แล้วกด **อนุมัติ** หรือ **ไม่อนุมัติ** หากไม่อนุมัติต้องระบุเหตุผลอย่างน้อย 3 ตัวอักษร
4. ตรวจข้อความในหน้าต่างยืนยัน แล้วกด **ยืนยันผล** ระบบบันทึกชื่อครูผู้พิจารณาและเหตุผลลง Sheet การลา และพยายามแจ้งผลไปยัง LINE OA ของนักเรียน
5. กด **เปิด Sheet การลา** หากต้องดูข้อมูลใน Google Sheet บัญชี Google ของครูต้องได้รับสิทธิ์เข้าถึงไฟล์นี้เช่นกัน

คำขอที่พิจารณาแล้วไม่สามารถกดอนุมัติหรือไม่อนุมัติซ้ำจากหน้าเว็บได้

## 5. เมื่อใช้งานติดขัด

- **LINE แจ้งว่าเซสชันหมดอายุหรือยืนยันตัวตนไม่ได้:** ปิดหน้าเดิม แล้วเปิดเว็บจากปุ่มใน LINE OA อีกครั้ง หากเปิดจากเบราว์เซอร์ ให้กดเข้าสู่ระบบด้วย LINE ใหม่
- **รหัสนักเรียนถูกใช้แล้ว หรือข้อมูลลงทะเบียนผิด:** แจ้งครูเพื่อช่วยตรวจข้อมูล อย่าสร้างบัญชี LINE ใหม่เพื่อกรอกรหัสซ้ำ
- **ความก้าวหน้าขึ้นว่าไม่ซิงก์:** กด **ลองอีกครั้ง** เมื่ออินเทอร์เน็ตพร้อม อย่าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ก่อนซิงก์สำเร็จ
- **โค้ด Code Lab/Workshop ไม่ปรากฏในอีกเครื่อง:** โค้ดร่างไม่ได้ซิงก์ข้ามอุปกรณ์ ให้ใช้เครื่องเดิมหรือไฟล์ HTML ที่ดาวน์โหลดไว้
- **ไม่มีข้อความแจ้งผลลาใน LINE:** เปิด **ประวัติการลา** เพื่อตรวจสถานะล่าสุด และให้ครูตรวจคำขอจากหน้าเว็บครู
- **ครูกดเปิด Google Sheet แล้วถูกปฏิเสธสิทธิ์:** ขอให้เจ้าของ Sheet แชร์ไฟล์การเรียนหรือการลาให้บัญชี Google ที่ใช้เปิดไฟล์
- **ครูรีโหลดหน้าแล้วต้องล็อกอินใหม่:** เข้าสู่ระบบอีกครั้ง เซสชันครูในเว็บเก็บไว้ชั่วคราวและมีอายุจำกัด

## 6. ข้อมูลที่ระบบเก็บ

- **Sheet การเรียน:** ข้อมูลลงทะเบียนนักเรียน ห้อง คะแนน บทเรียนที่จบ และสถานะ Code Lab/Workshop
- **Sheet การลา:** ข้อมูลนักเรียนสำหรับการลา คำขอ ช่วงเวลา สถานะ และคำชี้แจงของครู
- **ในเบราว์เซอร์ของนักเรียน:** โค้ดร่าง Code Lab/Workshop และข้อมูลการเรียนที่ยังรอซิงก์

Google Sheet ทั้งสองไฟล์ควรคงการแชร์แบบ **Restricted / จำกัด** เพราะมีข้อมูลนักเรียน ครูควรใช้ข้อมูลเท่าที่จำเป็นต่อการสอนและการพิจารณาคำขอ
